# Hitchload — сайт попутных грузоперевозок по Канаде

«Hitchload» — рабочее название. В нём два слова: *hitch* (поехать попуткой, «автостоп») и *load* (груз). Название меняется одной переменной `BRAND_NAME`, без правки кода.

| Папка | Что это |
|---|---|
| `web/` | **Сайт**: главная, поиск водителей по маршруту, доска грузов, регистрация, кабинет клиента, кабинет водителя, юридические страницы |
| `server/` | API, база данных, платежи, письма, SMS, push-уведомления в браузере, фоновые задачи. Сервер же отдаёт сайт и админку |
| `admin/` | Админка по адресу `/admin/`: проверка водителей, заказы, споры, отчёт CRA |
| `mobile/` | Приложение iOS/Android (на потом). Работает с тем же сервером |

## Что умеет сайт

**Клиент (отправитель):**
- Ищет водителей по маршруту «откуда → куда» и дате. Видит поездки с промежуточными городами, временем выезда и временем прохождения своих городов, всё на карте.
- Отправляет груз с конкретным водителем или размещает заказ для всех. Указывает адреса, размер, фото, объявленную стоимость, страховку по желанию, окно погрузки «с–до» и получателя.
- Торгуется: одно встречное предложение с каждой стороны.
- Регистрируется по SMS-коду, затем указывает имя, email и согласие с условиями.
- Привязывает карту (Stripe). Деньги списываются в момент, когда водитель подтвердил заказ.
- Получает подтверждения по email (адрес подтверждается по ссылке) и уведомления в браузере.
- Видит, где водитель, и PIN для получателя. Общается в чате, где контакты скрываются.
- Может отменить заказ и заранее видит точную сумму удержания. Ставит оценку, открывает спор.
- **Оповещения по маршруту:** кнопка «Сообщить мне». Когда любой водитель публикует поездку через оба города, приходит письмо и push. Отписаться можно одной ссылкой из письма.
- Если у клиента уже есть открытый заказ, а на его маршруте появился водитель, клиент получает уведомление и может одной кнопкой предложить заказ этому водителю.

**Водитель:**
- Подаёт анкету на одной странице:
  - данные и машина;
  - права, регистрация, справка о несудимости, страховка;
  - проверка документа и селфи (Stripe);
  - счёт для выплат (Stripe);
  - тест по правилам;
  - отправка на проверку.
- **Маршруты:** водитель в любой момент публикует поездку: откуда, города по пути, куда, время выезда, свободное место. Сайт сразу:
  - показывает грузы по этому маршруту, которые попадают во время его проезда;
  - уведомляет всех клиентов с подходящими открытыми заказами и оповещениями.
  - Новые грузы, размещённые позже вдоль поездки, приходят водителю уведомлением. По каждому грузу одно уведомление, с указанием, к какой поездке он подходит.
- Лента грузов рядом и по поездкам. Pro-водители видят заказы первыми, по остальным идёт таймер.
- Выполнение заказа:
  - взять заказ или предложить свою цену;
  - «еду на погрузку»;
  - фото при погрузке, «везу»;
  - PIN получателя (10 попыток);
  - выплата.
- Заработок, налоговые данные (SIN/BN), отказ от заказа, оценка клиента.

**Публичные страницы:**
- главная, «Как это работает», «Цены», «Безопасность», «Вопросы», «Для водителей»;
- доска открытых грузов (только города, без адресов);
- условия и политика конфиденциальности: **черновики для юриста**;
- английский и русский языки;
- адаптивная вёрстка для телефона, тёмная тема, `sitemap.xml`, `robots.txt`, превью для соцсетей.

**Время** в письмах и SMS указывается по часовому поясу провинции, к которой оно относится. Например, «Nov 19, 10:00–14:00 MST» для Альберты.

## Что проверено

- **Сервер — 40 автотестов на настоящем PostgreSQL.** Весь цикл заказа, отмены, споры, выплаты, страховки водителей. Плюс новое:
  - маршруты в обе стороны;
  - оповещения и отписка;
  - запрос заказа конкретному водителю;
  - публичный поиск, который не раскрывает адреса;
  - подтверждение email;
  - браузерный push: шифрование по RFC 8291 проверено расшифровкой, подпись VAPID проверена.
- **Сайт — 10 браузерных тестов (Chromium):**
  - главная → поиск → регистрация → оповещение;
  - заказ с тестовой картой → водитель берёт заказ, у клиента статус обновляется без перезагрузки;
  - чат скрывает телефон;
  - фото, неверный и верный PIN, оценка;
  - водитель публикует маршрут, клиент получает уведомление и переходит к поездке;
  - подтверждение email;
  - полная анкета нового водителя;
  - мобильная вёрстка без горизонтальной прокрутки, русский язык, все статические страницы, 404;
  - отсутствие ошибок JavaScript.
- Админка — 7 браузерных тестов. Мобильный API-клиент — 4 теста.

## Что НЕ проверено (сделать до рекламы)

1. **Реальные внешние сервисы не вызывались ни разу:** Stripe (карты, выплаты, проверка личности), Twilio (SMS), Resend/Postmark (письма), push через Chrome/Firefox/Safari, S3. В тестах вместо них заглушки. Код написан по их документации. Первый прогон делайте в тестовом режиме Stripe.
2. **Push в настоящем браузере.** Шифрование проверено расшифровкой по стандарту, но отправку через сервер Google или Apple я не делал. Это проверяется за 5 минут на живом домене с HTTPS. На iPhone push работает только если сайт добавлен на экран «Домой» (iOS 16.4+).
3. **Карта и шрифты грузятся с внешних CDN (unpkg, Google Fonts).** Здесь они были недоступны, поэтому тесты шли на запасной схеме маршрутов без подложки. На живом сайте будет настоящая карта. Тайлы `tile.openstreetmap.org` подходят только для старта; при росте трафика нужен платный поставщик тайлов (переменная `MAP_TILES_URL`).
4. **Без ключа Google адрес вводится как «улица + город из списка».** Расстояние и цена тогда считаются от центра города, и для заказов внутри города это неточно. Для запуска **нужен** `GOOGLE_MAPS_BROWSER_KEY` (Places API New).
5. **Свободность названия «Hitchload» проверена только поиском в интернете.** Приложений и компаний с таким названием я не нашёл. Домены `.ca` и `.com` и товарный знак CIPO отсюда проверить не удалось: проверьте у регистратора и в базе CIPO до покупки рекламы.
6. **Юридическое:**
   - условия и политику должен утвердить юрист;
   - страховку груза клиентам можно продавать только через лицензированного партнёра;
   - для Квебека по закону 96 нужен французский язык. Сейчас на сайте английский и русский.

## Проверка на Render (бесплатно, тестовый режим)

В корне лежит `render.yaml`: по нему Render сам создаёт сервер и базу.

1. Залейте проект в репозиторий GitHub.
2. На render.com нажмите **New → Blueprint**, выберите репозиторий и нажмите **Apply**.
3. Render спросит `ADMIN_PHONES`: впишите свой номер в формате `+1780XXXXXXX`.
4. Сборка идёт 5–10 минут. Потом откройте ссылку вида `https://hitchload-XXXX.onrender.com`.

Режим работы — тестовый:
- SMS-код показывается прямо на странице;
- карта тестовая;
- проверка водителя и выплаты симулируются;
- письма уходят только в лог Render.

Демо-водители: `(780) 555-0200` (Pro) и `(780) 555-0300` (Basic). У них уже есть поездки Эдмонтон → Ред-Дир → Калгари.

Ограничения бесплатного Render:
- сервер засыпает через 15 минут без посещений, первое открытие после этого ждёт около минуты;
- база удаляется через 30 дней (плюс 14 дней на продление);
- фото без S3 хранятся в самой базе (до 1 ГБ на бесплатном тарифе);
- регион — США, канадского региона у Render нет.

Для реальной работы нужны платный тариф, `NODE_ENV=production`, все ключи и хранилище S3.

## Запуск на компьютере

```bash
docker compose up --build                       # сайт: http://localhost:8080   админка: /admin/
docker compose exec api node dist/db/seed.js    # демо-водители и поездки Эдмонтон → Ред-Дир → Калгари
```

Без ключей всё работает в тестовом режиме:
- SMS-код показывается прямо на странице;
- карта сохраняется кнопкой «тестовая карта»;
- проверка личности и выплаты симулируются;
- письма печатаются в консоль сервера.

В production без ключей Stripe сервер не стартует.

Без Docker:
```bash
(cd web && npm install && npm run build)
(cd admin && npm install && npm run build)
cd server && npm install && cp .env.example .env    # заполните DATABASE_URL, для локального запуска NODE_ENV=development
npm run seed && npm run dev
```

Тесты:
```bash
cd server
npm run test:local                                     # 40 тестов
npx playwright install chromium
scripts/with-test-db.sh node --import tsx --test test/e2e/site.e2e.ts    # сайт
npm run test:admin-ui                                  # админка
```

## Что нужно от владельца

| Что | Зачем | Переменная |
|---|---|---|
| Компания в Канаде, банковский счёт | Stripe, договоры | — |
| **Домен** (например `hitchload.ca`) и хостинг с HTTPS | Сайт; push и Stripe работают только по HTTPS | `PUBLIC_URL` |
| Хостинг Node.js + PostgreSQL 16 в Канаде (Render, Railway, DigitalOcean, AWS) | Сервер и база | `DATABASE_URL` |
| **Stripe**: Connect (Express, Канада) + Identity; webhook на `https://ВАШ-ДОМЕН/webhooks/stripe` | Карты, выплаты, проверка водителей | `STRIPE_*` |
| **Twilio**: Verify Service + номер | Коды входа, SMS получателю с PIN | `TWILIO_*` |
| **Resend** или **Postmark**, домен подтверждён (SPF/DKIM) | Письма: подтверждения, чеки, оповещения | `EMAIL_*` |
| Ключи VAPID: `cd server && npm run vapid` | Push-уведомления в браузере | `VAPID_*` |
| **Google Cloud**: Places API (New), ключ с ограничением на ваш домен | Точные адреса и цены | `GOOGLE_MAPS_BROWSER_KEY` |
| Поставщик тайлов карты (MapTiler, Stadia) — когда пойдёт трафик | Карта | `MAP_TILES_URL`, `MAP_ATTRIBUTION` |
| Хранилище S3 (`ca-central-1`) | Фото грузов и документы водителей | `S3_*` |
| Юрист | Условия, политика (PIPEDA), статус посредника, CRA Part XX, французский для Квебека | — |
| Страховой брокер / лицензированный партнёр | Страховка груза для клиентов | `INSURANCE_RATE` |
| Сервис проверки судимости (Certn, Triton) | Проверка водителей (сейчас справка загружается водителем и принимается в админке) | — |

Секреты генерируются так:
```bash
openssl rand -base64 48   # JWT_SECRET
openssl rand -base64 32   # DATA_ENCRYPTION_KEY — не терять и не менять: им зашифрованы SIN/BN водителей
```

## Развёртывание

1. `docker build -t hitchload .` из корня. Образ собирает сайт, админку и сервер.
2. Запустите образ с переменными из `server/.env.example`. Миграции базы применяются сами при старте.
3. Нужны HTTPS и поддержка WebSocket на `/v1/ws`. Сервер держите в одном экземпляре: фоновые задачи пока не рассчитаны на несколько копий.
4. В Stripe добавьте webhook на `https://ВАШ-ДОМЕН/webhooks/stripe` с событиями:
   - `account.updated`
   - `identity.verification_session.verified`
   - `identity.verification_session.requires_input`
   - `identity.verification_session.canceled`
   - `setup_intent.succeeded`
   - `charge.dispute.created`
5. Укажите свой телефон в `ADMIN_PHONES`. Войдите на `/admin/` и проверяйте анкеты водителей.
6. Включите ежедневные бэкапы базы.
7. Перед рекламой пройдите весь путь сами на живом домене, с настоящей картой в тестовом режиме Stripe:
   - клиент;
   - водитель;
   - заказ;
   - доставка;
   - push на телефоне.

## Правила (меняются переменными окружения)

- Комиссия: 5% с клиента и 5% с водителя.
- Страховка груза: 1.5% от стоимости, минимум $3, при любой стоимости.
- Карта обязательна. Деньги списываются, когда водитель подтвердил заказ.
- Окно приоритета Pro: 150 секунд по городу, 30 минут по межгороду.
- Лимиты груза:
  - Basic — $1 000, со страховкой заказа $5 000;
  - Pro — до лимита своего полиса.
- Отмена клиентом:
  - до подтверждения — бесплатно;
  - после подтверждения — 5% водителю + 5% платформе;
  - меньше чем за 24 ч или когда водитель уже выехал — 30% + 10%;
  - клиент не явился — 40% + 10%;
  - сервисный сбор после подтверждения не возвращается.
- Совпадение маршрута: город погрузки и город доставки должны быть в пределах 30 км от остановок поездки и идти в правильном порядке. Время проезда считается по средней скорости 90 км/ч, расстояние — по прямой ×1.25.
